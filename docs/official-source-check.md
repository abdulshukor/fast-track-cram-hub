# Official source reference starting points

This is a **point-in-time reference index**, not a continuously updated service. Exam policies, domain definitions, numerical limits and versions can change; re-check primary sources whenever creating or updating a certification package.

- [AWS Certified DevOps Engineer – Professional (DOP-C02) exam guide](https://docs.aws.amazon.com/aws-certification/latest/devops-engineer-professional-02/devops-engineer-professional-02.html) — six domains in the official blueprint as checked in October 2026.
- [Microsoft Azure Administrator (AZ-104) official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104) — use Microsoft Learn for the applicable skills measured date.
- [AWS Certification portal](https://aws.amazon.com/certification/) — exam registration, updates and retirement notices.
- [Microsoft Credentials](https://learn.microsoft.com/en-us/credentials/) — certification paths and exam updates.
- [CNCF certifications](https://www.cncf.io/training/certification/) — CNCF/Linux Foundation exam information.
- [HashiCorp certifications](https://www.hashicorp.com/certification) — current exam versions and objectives.

Do not copy official exam question banks or use leaked questions. Public content should be original, objective-aligned, and traceable to official documentation.
