# Local-only reference material

The original reference website screenshots, recording, and video keyframes are **not included in this public repository**. They may belong to third parties and should not be uploaded without explicit redistribution permission.

If you have your own authorized reference material, place it locally in `references/screenshots/`, `references/video/`, or `references/private/`. These folders are ignored by Git. The application runs without them.

Use `docs/FEATURES.md` as the public functional specification.
