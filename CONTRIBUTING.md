# Contributing to CertCram Pro

Thanks for helping make certification preparation more useful and accurate. This is an early-stage community project.

1. Search existing issues; open an issue before large refactors or new certification packages.
2. Fork, create a feature branch, and use `npm ci`.
3. Keep changes small, reusable, and certification-neutral in shared UI components.
4. Add tests for every bug fix or new interaction. Run `npm run verify` and `npm run test:e2e` if browser tooling is available.
5. When authoring certification content, cite the **current official exam guide**, include verification dates, use original questions and explain distractors. Do not contribute exam dumps, trademarks you do not have rights to redistribute, or material from a paid training provider.
6. Keep reference media, personal progress exports, cloud credentials and `.env.local` out of commits.
7. Describe functionality honestly; `partial` content is welcome if explicitly labeled. Never label a course exam-ready based on counts alone.
8. Create a pull request using the template. Maintainers may request content revisions or tests before merging.

See [Code of Conduct](CODE_OF_CONDUCT.md), [Security policy](SECURITY.md), and [Content standards](docs/CONTENT_STANDARDS.md).
